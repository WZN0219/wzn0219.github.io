## Edit and preview

Edit index.html for content and assets/style.css for styling. Open index.html in a browser, or run `python -m http.server 8765 --bind 127.0.0.1` from this directory. Push main to update GitHub Pages. The portrait and both emblems are served locally from assets/images/.
