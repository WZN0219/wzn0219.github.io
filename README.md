# 吴泽楠 / Zenan Wu — 个人主页框架

面向 GitHub Pages 的纯静态主页，无需安装依赖。内容仍为待补充的框架；通过 GitHub Pages 发布。

## 预览

直接用浏览器打开 index.html。或在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765/ 。

## 待补充内容

- 照片：放入 assets/images/portrait.jpg，将照片占位块替换为 `<img class="portrait portrait-image" src="assets/images/portrait.jpg" alt="吴泽楠">`。
- 简介：当前身份、研究方向、三至五句自述、公开邮箱与学术主页。
- 教育：学校、专业、学位、起止时间。
- 实习：公司或实验室、团队、职位、时间、可以公开的贡献。
- 论文：完整标题、作者顺序及本人署名、会议或期刊、年份、图片、介绍和相关链接。

内容编辑 index.html；版式编辑 assets/style.css。方括号均为占位，不代表已确认的信息。公开简历可放入 assets/files/。

网页地址：https://wzn0219.github.io/ 。修改内容后提交并推送 main 分支，GitHub Pages 会自动更新。
